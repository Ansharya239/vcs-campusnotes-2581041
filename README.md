# CampusNotes

CampusNotes is a simple project created as part of the
Version Control Systems (CSE25303) assignment.

## Purpose
To understand and practice Git and GitHub workflows.

## Topics
- Git Basics
- Remote Repositories
- Branching
- Pull Requests
- Version Control

## Course Note Template

The project includes a reusable course note template located at:

`templates/course-note-template.md`

The template provides sections for:

- Course name and topic
- Date in YYYY-MM-DD format
- Key concepts
- Summary
- Examples
- Questions
- References

Students can use this template to organize their academic notes consistently.
